# 🔊 Sound Files Directory

## Required Files:

Place the following MP3 files in this directory:

1. **move.mp3** - Played when a player makes a move
2. **win.mp3** - Played when a player wins
3. **lose.mp3** - Played when AI wins
4. **draw.mp3** - Played when game ends in a draw
5. **click.mp3** - Played on button clicks

## 📥 Where to Get Sounds:

### Free Sound Libraries:
- **Freesound.org**: https://freesound.org/
- **Zapsplat**: https://www.zapsplat.com/
- **Mixkit**: https://mixkit.co/free-sound-effects/

### Quick Recommendations:

**For move.mp3**: Search for "pop", "click", or "tick"
**For win.mp3**: Search for "success", "victory", or "achievement"
**For lose.mp3**: Search for "fail", "lose", or "sad"
**For draw.mp3**: Search for "neutral", "end", or "complete"
**For click.mp3**: Search for "button", "click", or "tap"

## ⚠️ Important:

The game will work perfectly fine **without these files**! 
Audio is optional and the app handles missing files gracefully.

## 🎵 File Specifications:

- Format: MP3
- Duration: 0.5 - 2 seconds
- Size: < 50 KB each
- Sample Rate: 44.1 kHz

## 🚀 After Adding Files:

1. Place MP3 files in this directory
2. Run: `flutter pub get`
3. Restart the app
4. Enable sound in settings
5. Enjoy the audio feedback!
