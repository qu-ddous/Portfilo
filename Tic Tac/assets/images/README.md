# Image Assets

This folder is reserved for future image assets such as:

- App logo
- Player avatars
- Achievement badges
- Background images
- Custom icons

Currently, the app uses Material Icons and doesn't require any image assets to function.

## Future Assets

When adding images, follow these guidelines:

- Use PNG format with transparency
- Provide multiple resolutions (1x, 2x, 3x)
- Optimize file sizes
- Use descriptive filenames

## Example Structure

```
images/
├── logo.png
├── logo@2x.png
├── logo@3x.png
├── avatars/
│   ├── avatar1.png
│   └── avatar2.png
└── achievements/
    ├── badge1.png
    └── badge2.png
```
